# Markdown URL Preview
https://markdown-viewer-one.vercel.app

Turn any markdown URL into a shareable, beautifully rendered preview link.

## Features
 - Convert any online markdown URL into a rendered preview page
 - Support for GitHub markdown files url (e.g. https://github.com/Emiyaaaaa/markdown-url-preview/blob/main/README.md)

## How to use
Replace your markdown url: https://markdown-viewer-one.vercel.app/?url=[REPLACE_YOUR_MARKDOWN_URL]
